# obsidian-work

- `vault-share/` – self-hosted, login-protected web viewer for Obsidian vaults, styled like the Obsidian app.
- `microsidian/` – Microsidian Obsidian plugin (from Crumpet-Sniffer/Microsidian).
- `vault-share/viewer/` – build source for the in-browser Word/PowerPoint viewer (`npm install && npm run build` writes `vault-share/static/office.js`).
